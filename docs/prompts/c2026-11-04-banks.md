## ADDED Requirements

### Requirement: Catálogo global Bank (dominio Banks)
El sistema SHALL persistir bancos como catálogo global sin `company_id`, en el
dominio Banks, con soft delete y status Active/Inactive (string + enum PHP).
Campos: name, slug, tradename, lei, eu_code, supervisor_code, swift,
swift_source, swift_updated_at.

#### Scenario: Sin tenancy
- **WHEN** se consulta el catálogo desde dos companies distintas
- **THEN** se ven los mismos registros globales

### Requirement: CRUD Admin Configuración / Bancos
El sistema SHALL exponer bajo Configuración → Bancos un Index ServerTable con
Acciones (toggle status, Edit, Delete confirm) y Create/Edit por modal.
Autorización vía Functionality `banks` y permisos `banks.*`. Index SHALL NOT
mostrar columna Estado textual si existe toggle en Acciones. Cuando el cliente
no envía sorts, el listado SHALL ordenar Active antes que Inactive y luego por
name.

#### Scenario: SA abre Bancos
- **WHEN** un usuario autorizado abre Configuración → Bancos
- **THEN** ve el Index ServerTable de banks

#### Scenario: Default Active-first
- **WHEN** se solicita el `table` de banks sin sorts
- **THEN** aparecen primero los Active y, dentro de cada grupo, por name

#### Scenario: Sin permiso
- **WHEN** un usuario sin `banks.viewAny` fuerza la URL del Index
- **THEN** recibe 403

### Requirement: Seeder bancos v1 con status del JSON
El sistema SHALL incluir un seeder que cargue bancos desde datos enriched v1,
preserve IDs, respete status Active/Inactive del origen, y quede documentado en
README § Seeders (comando Artisan explícito).

#### Scenario: Seed en entorno limpio
- **WHEN** se ejecuta el seeder de bancos en base limpia
- **THEN** existen los registros portados con los mismos IDs y el status del JSON


## MODIFIED Requirements

### Requirement: Ítem Bancos en Configuración
El menú Configuración SHALL incluir Bancos (Functionality `banks`) hacia el
Index del catálogo.

#### Scenario: SA ve Bancos en Configuración
- **WHEN** un Super Admin obtiene el menú Configuración
- **THEN** ve la entrada Bancos hacia el Index de banks
